C100 Keycap Designer

Every key can carry up to 4 commands, one per section of the cap, colour-coded by layer, the same colours as the LEDs: Layer 1 amber (keyboards), Layer 2 blue (Ableton control), Layer 3 green (sequencers). The 4th section is left empty (Shift only changes layer and page). Layer 4 (generative) is not printed. The 8x8 pads are included: their legends show the first page of each layer. Click a key to edit it. Made from your layout file (firmware v13, 2026-11-01).

Sections: top-left = layer 1, top-right = layer 2, bottom-left = layer 3, bottom-right = spare (empty). A key that does the same on every layer is one big legend.
