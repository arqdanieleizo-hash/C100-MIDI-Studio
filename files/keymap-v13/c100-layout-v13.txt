=== C100 8K KEYMAP (planner v6) ===
Board: Keychron C100 8K, 10 rows x 10 columns. R1 is the top row, C1 the left column.
The 8x8 pad area is R3 to R10 by C1 to C8 (bottom-left). Control keys: rows R1-R2 and columns C9-C10. R1C1 is also the flash-mode key.
4 main layers: 1 keyboards (7 pages), 2 Ableton control (5), 3 sequencers (4), 4 generative pages (3). Navigation = the 4 top-right keys (R1C9, R1C10, R2C9, R2C10): arrows by default; with Controls Shift held: PG+, L+, PG-, L-. Shift has no other job. Control keys come from the CONTROLS tables unless a page changes them: >C on a page = use the CONTROLS tables, >L = use page 1 of the layer.
Date: 2026-11-01

SETTINGS
knob_step: 4
knob_mode: absolute
transpose_step: 12
transpose_limit: 24
bpm: 120
seq_note: 36
bend_range: 48

KEYNOTE R1C1: Pitch bend up while held, glides back on release
KEYNOTE R1C2: Delete: hold it and tap a mini-sequencer step to clear that step. Double-tap = clear the whole selected sequence (on the step recorder: the whole track)
KEYNOTE R1C3: Shift: hold it and use the four arrow keys (top right) to change layer and page. This is the only job of Shift
KEYNOTE R1C4: Play / stop (CC 85 play, CC 86 stop) and the internal clock. On layer 1 page 1 it also restarts the mini sequencer
KEYNOTE R1C5: Board record: the mini sequencer records the drums and pianos you play while it runs. Flashes red while on. Ableton record is R4C9
KEYNOTE R1C6: MIDI channel for the whole board. Hold it and use the arrows: up / down = small step, right / left = big step. Pages and keyboards with their own channel keep it
KEYNOTE R1C7: Scale. Hold it: up / down = next / previous scale, right / left = Western / Non-Western bank. Shows the 2-letter scale name
KEYNOTE R1C8: Octave / transpose for everything. Hold it and use the arrows: up / down = small step, right / left = big step. (up/down 1 semitone, right/left 1 octave)
KEYNOTE R1C9: Arrow right (big step). With Controls Shift: page up (layer 1 has 7 pages, layer 2 has 5, layer 3 has 4, layer 4 has 3). Always an arrow, never replaced by a page
KEYNOTE R1C10: Arrow up (small step). With Controls Shift: next main layer
KEYNOTE R2C1: Pitch bend down
KEYNOTE R2C2: Copy the selected mini sequence. Double-tap = paste, then tap the first step
KEYNOTE R2C3: Undo (Ctrl+Z). Redo is R4C10
KEYNOTE R2C4: Scale quantize on / off: out-of-scale notes snap into the scale. Ableton Quantize (Ctrl+U) is R6C9
KEYNOTE R2C5: Tap tempo (CC 88) + internal tempo
KEYNOTE R2C6: Volume (CC 7) of the board channel. Hold it and use the arrows: up / down = small step, right / left = big step.
KEYNOTE R2C7: Tempo. Hold it and use the arrows: up / down = small step, right / left = big step. (up/down 1 BPM, right/left 10 BPM). Sends CC 89 relative to Ableton
KEYNOTE R2C8: Root note. Hold it and use the arrows: up / down = small step, right / left = big step. (up/down 1 semitone, right/left a fifth)
KEYNOTE R2C9: Arrow left (big step). With Controls Shift: page down
KEYNOTE R2C10: Arrow down (small step). With Controls Shift: previous main layer
KEYNOTE R4C9: Ableton record (CC 87). Board record is R1C5
KEYNOTE R4C10: Redo (Ctrl+Y). Undo is R2C3
KEYNOTE R6C9: Ableton Quantize (Ctrl+U). Scale quantize is R2C4
KEYNOTE R6C10: Clock source: tap = Auto (follows a MIDI clock from Ableton or another device when one arrives) / Internal only (ignores outside clock, start and stop). Orange while an outside clock is running. The pads show AU or IN
KEYNOTE R8C9: Rolled chords: tap = on / off (chord keys play their notes one after another). Hold it + arrows: up / down = speed (slow harp ... fast guitar), right = direction (up / down / alternate), left = velocity ramp (flat / rising / falling)
KEYNOTE R9C9: Effects key. Tap = effects on / off for everything you play. Hold a note (or a step recorder track step) and tap = only that keyboard or track. Hold = rows 3-8 show the effects: columns 1-2 = 12 effects (tap = edit its faders, double-tap = on / off), columns 3-8 = its faders. Lit while the keyboard or track you played last has effects on
KEYNOTE R9C10: Effects off on every keyboard and track. Effects key + this key = MIDI kill switch (all notes off, stops everything)
KEYNOTE R10C9: Arpeggiator: double-tap = on / off for everything you play. Hold = the top 4 grid rows show the arp settings. Hold + up / down = pattern, left / right = cadence stop bars. Rolled chords are R8C9
KEYNOTE R10C10: Hold = sustain (CC 64). Double-tap = latch on / off (notes keep playing after you let go; press one again to stop it)

LAYER 4 PAGE 1 "Random walk"
colors: #34c759 #5ac8fa #ff9f0a #ff2d95
channel: global
led: auto
purpose: Random walk with up to 4 walkers (each its own colour and MIDI channel). Each walker moves on the 8x8 grid every tick: X = pitch (scale degree 1-8 of the selected scale and root), Y = velocity or a CC. Tap a pad = put the selected walker there (and switch it on). R3C9-R6C9 = select walker 1-4, R3C10-R6C10 = walker 1-4 on / off. The settings are keys you HOLD while you tap the arrows: R7C9 channel of the selected walker, R7C10 run on / off (tap), R8C9 rate, R8C10 step size, R9C9 pull to centre, R9C10 Y mode / CC number, R10C9 octave, R10C10 gate. Needs Play. Plays only while this page is on screen
led_note: Each walker in its own palette color (walker 1-4 = colors 1-4), its last 3 positions dimmer, the field dim white. Select keys: selected walker white, others dim. On / off keys: walker color when on, very dim when off.

LAYER 4 PAGE 2 "Pond"
colors: #00b4ff #5e5ce6 #ffffff #64d2ff
channel: global
led: auto
purpose: Pond: the 8x8 pad is a water surface. A pad press drops a pebble (it plays its own note) and ripples spread out. Where ripples overlap their heights add up; when the height at a cell passes the threshold, that cell plays its note. Notes are in the selected scale and root: +1 scale step per column, +3 per row. Wave height sets the velocity and a filter CC (CC 74 by default): big waves are loud and bright, fading ripples soft and muffled. Drum mode: the wave height picks the drum (36-43). Settings: HOLD a key in columns 9-10 (R3-R7) and use the arrows. R7C10 = melodic / drum mode, R8C9 = clear ripples. Plays only while this page is on screen. No Play key needed
led_note: Wave crests in the main color (brighter = higher), troughs dim in color 2, the pebble flashes white.

LAYER 4 PAGE 3 "Constellation"
colors: #ffd60a #5ac8fa #ffffff #ff375f
channel: global
led: auto
purpose: Constellation: tap pads to place anchors (max 20, tap an anchor again to remove it). The anchors are joined by a nearest-neighbour path; a playhead runs along each path on the 16th clock (needs Play). On an anchor it plays a sustained chord from the in-key grid (held until the next anchor); on the cells in between it plays short notes (straight and diagonal). Shape sends CCs: area and perimeter = filter cutoff (CC 74), number of empty keys = reverb send (CC 91), number of anchors = maximum velocity. Arrows: up / down = BPM, left / right = maximum connection distance (low = several small sequences run at once). R10C10 = clear. Plays only while this page is on screen
led_note: Anchors bright in the main color, path dim in color 2, playhead white.
